# Screen 10 — Dialog: Select Audio to Delete

Screenshot: `App Screenshots/10.png` (Pink theme, 1080×2340, 440dpi)

## What it is

Modal dialog opened from Nav drawer > "Delete Downloads". Lists only surahs that have cached audio (browser Cache API, cache name `quran-audio`). User selects surahs to delete; "Delete Selected" removes those cache entries.

## Layout

- Material3 AlertDialog shape: `border-radius: 28px`
- Title: "Select Audio to Delete", `color: var(--color-primary)`, bold, 20sp
- Toggle link: "Check All" / "Uncheck All", color `#1976D2`, underlined, 14sp
- Scrollable checkbox list (only cached surahs; empty if none)
  - Each row: checkbox + `Surah N: <myanmar name>`
  - Surah 1 is always `disabled` (locked — cannot be deleted), text gray `#9E9E9E`
  - Checkbox checked color: `#D81B60` (softPinkUI, constant)
- Footer (below list):
  - "N Surah selected." — gray `#9E9E9E`, 14sp
  - "Freed up size: X.X MB" — `#D81B60`, bold, 14sp
- Buttons:
  - Close: TextButton, `color: var(--color-primary)`, uppercase, 14sp
  - Delete Selected: rounded pill, bg `#D81B60`, text white; disabled = Material3 gray (`rgba(0,0,0,0.12)` bg, `rgba(0,0,0,0.38)` text)

## Audio cache URL pattern

`/audio/Quran_32kbps/NNN/NNNNNN.mp3` (NNN = zero-padded surah, NNNNNN = surah+ayat)
Cache name constant: `AUDIO_CACHE_NAME = 'quran-audio'` (defined in `pwa/src/data/audioCache.ts`)

## Android source

`MainActivity.kt:994–1075` — `showAudioDeleteDialog`, `deletableSurahs`, `startDeleteProcess`

## PWA delta from Android

Android checks `filesDir/audio/Quran_32kbps/<id>/` dirs. PWA checks Cache API entries matching the audio URL pattern. Delete removes those cache entries (no filesystem).
