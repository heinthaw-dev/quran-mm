# Screen 04 — Info Viewer: Preface

Route: `/info/preface` (also `/info/introduction`, `/info/biography`, `/info/developer`)
Screenshot: `App Screenshots/04.png`
Android source: `app/MainActivity.kt` ~1235–1261 (full-screen Dialog, not Activity)

## Layout

Full-screen Dialog over `Surface(color = currentTheme.bg)`:

### Top bar (Row, padding: horizontal=16dp, vertical=12dp)
- ArrowBack icon, 28dp, tint = primary → navigate back
- Spacer 16dp
- Title text (e.g. "Preface"), 20sp, bold, color = primary, weight=1
- Close icon, 28dp, tint = primary → navigate back (also closes nav drawer in Android)
- `HorizontalDivider(color = primary.copy(alpha=0.3f))` below the row

### Content card (Surface below top bar)
- color = Color.White
- shape = RoundedCornerShape(16dp)
- shadowElevation = 4dp
- outer padding: start=16, end=16, top=16, bottom=64
- inner WebView padding: 12dp all sides
- WebView loads `file:///android_asset/<page>.html`

## HTML content files
- `assets/preface.html` → `/data/preface.html` (copied by sync-assets)
- `assets/introduction.html` → `/data/introduction.html`
- `assets/biography.html` → `/data/biography.html`
- `assets/developer.html` → `/data/developer.html`

## HTML content classes (from preface.html)
- `h2`: 22px, centered, color=#4B559C (use `var(--color-primary)` in PWA)
- `.arabic`: 22px, bold, centered, RTL, direction=rtl
- `.title`: 20px, bold, centered, color=#4B559C
- `.quote`: margin L/R 16px, italic, color=#555555
- `.author`: right-aligned, italic, font-weight bold
- `body`: 16px, line-height 1.8, color=#333333, text-align justify

## PWA approach
Fetch `/data/<page>.html`, parse with DOMParser, extract `body.innerHTML`
(strips the `<style>` block to prevent CSS leaking), render with
`dangerouslySetInnerHTML` inside CSS Module that defines the same classes
but uses tokens — making title/h2 color theme-aware.
